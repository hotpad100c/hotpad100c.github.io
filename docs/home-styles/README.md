这里是几种首页布局的候选方案，数据（文章、项目、标签）都取自博客本身，选中后可以直接替换 `docs/README.md` 作为正式首页。

- [终端 Terminal](/home-styles/terminal/)：深紫 CRT 终端，用命令行输出来组织首页内容。
- [杂志 Editorial](/home-styles/editorial/)：淡紫纸面 + 衬线大标题，头条 / 次要文章 / 目录的报刊排版。
- [蓝图 Blueprint](/home-styles/blueprint/)：工程图纸网格，文章是「零件清单」，项目是「外购件」，带方块更新示意图。
- [便当网格 Bento](/home-styles/bento/)：圆角卡片拼贴，跟随站点深浅色模式。

第二轮（杂志的克制 + 便当网格的排版，方正 / 平行四边形，保留 bg-cube 背景图）：

- [方格 Grid](/home-styles/grid/)：bg-cube 通栏首屏，下方是 1px 发丝线拼成的深色方格网格。
- [斜切 Slant](/home-styles/slant/)：bg-cube 做整页暗化背景，所有卡片、按钮、导航都是平行四边形。
- [封面 Cover](/home-styles/cover/)：浅色纸面，墨线方格，bg-cube 作为 2×2 的封面格。
